# Cold Frame

Concept promotional site for a fictional open pollinated seed company.

**Brief it answers:** a small grower selling a catalogue, where the useful
thing is knowing what to sow and when, not the branding.

## Direction
Risograph. Two spot inks, a deliberate misregistration on the display lines, a
halftone paper overlay and hard offset shadows. Nothing is smooth.

- Display type: the system grotesk, very heavy
- Palette: #f6f1e4 paper, #1f2419 ink, #ff4d6d pink, #2e7d50 green

## What works
- A twelve month sowing calendar with real contents per month, under glass and
  direct outside, opening on the current month
- A catalogue of twelve varieties filtered on three axes at once: light, where
  you are growing, and how much attention it needs
- A seed box that adds up, with quantities, postage and a confirmation

## Running it
Open `index.html`, or serve the folder with any static server. No build step,
no network request, no image files.

```
index.html    markup
styles.css    page furniture, ink layers
script.js     calendar, catalogue, seed box
```
