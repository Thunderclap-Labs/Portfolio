# Vilnis Type

Concept promotional site for a fictional type foundry.

**Brief it answers:** a foundry selling one family, where the product is the
typography, so the page cannot lean on anything else.

## Direction
Swiss. White, black, one red. A strict grid, no rounded corners, no shadows,
no illustration. Everything that looks like decoration is a specimen.

- Type: the system grotesk, set very large and very small and nothing between
- Palette: #ffffff paper, #101010 ink, #e4002b red

## What works
- A working type tester: size, weight, tracking, leading, case and style, all
  applied live to a field you can type into
- A nine weight specimen list
- A glyph table of a hundred and ninety characters, filterable by category,
  with a zoom panel showing the selected glyph large
- A licence calculator: package, seats, web traffic and app installs, priced
  as you change it

## Running it
Open `index.html`, or serve the folder with any static server. No build step,
no network request, no image files and no web fonts.

```
index.html    markup
styles.css    page furniture
script.js     tester, specimen, glyph table, licence calculator
```
